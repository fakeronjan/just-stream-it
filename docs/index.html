Keeper cost = original 2025 draft round minus one (round 1 stays round 1, but costs a second keeper slot - only the round is enforced, not an exact pick). ADP uses ESPN's SUPERFLEX rank (this league starts a QB + a superflex slot, so standard/PPR rank badly undervalues QBs). Keeper Value compares keeper cost to current SUPERFLEX market value, in picks - positive is a bargain, negative is an overpay. The suggested plan shortlists a few options per price band (premium/mid/value), best Keeper Value first - a portfolio heuristic, not a rule, and it won't always make sense for your roster. Options worse than a full round's overpay are left off the shortlist entirely - keepers aren't mandatory, and it's often better to let a bad-value slot go back into the draft pool than keep it.
